Cách dùng tài liệu

Đọc đúng thời điểm để tránh học kiến trúc chỉ trên giấy.

1 · Trước khi code

Đọc mục tiêu batch, sơ đồ flow và cột “Tại sao”. Chỉ mở những file thuộc batch đó.

2 · Sau khi code

Đi từng dòng trong bảng file; trả lời được Input, Logic, Output, Failure rồi mới chạy Ruff/test.

3 · Sau phase

Review luồng end-to-end, dependency direction, invariants và evidence trước khi mở phase kế tiếp.

Quy ước quan trọng: ĐÃ KIỂM nghĩa là có code và evidence đã chạy; ĐANG LÀM là code draft chưa qua gate; TO-BE là placeholder/kế hoạch, không được trình bày như tính năng đã tồn tại.

Acceptance language

OFFLINE_VERIFIED: fake/local tests pass.

LIVE_BLOCKED: thiếu credential/environment/permission.

LIVE_ACCEPTED: provider/infrastructure thật đã chạy với assertions và artifacts.
